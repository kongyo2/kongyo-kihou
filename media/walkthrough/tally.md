# 月一で集計を見る

ステータスバーの `×n －n B=0.xxx` をクリックする。集計するのは三つだけ。

| 指標 | 意味 |
| --- | --- |
| `×` の絶対数 | 外れの数 |
| `－` の絶対数 | 射程を書き損ねた数 |
| ブライアスコア | `Σ(p − o)² / n`。`[易]` を除外して算出 |

**`○` の数は集計しない。** 集計した瞬間、当たりやすい予測ばかりが選抜される。この拡張の内部にも「当たりの件数」を返す関数は存在しない。

`p ≥ 0.90` / `p ≤ 0.10` の易問は、`[易]` の標示が無くても集計の主成分から除外される。標示の有無で抜け道は作れない。
