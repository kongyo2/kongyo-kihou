# 鋳造する

`Ctrl+Alt+K`（macOS は `Cmd+Alt+K`）。気分の一文を選択したまま押すと、それを種にウィザードが開く。

```
却下：このPRはたぶん今週中に通る
鋳造：[2026-08-04] P1 p=0.60 D=2026-08-11T23:59 S=PR#412 O=mergedフラグ C=true J=GitHub API R=外れたら、レビュー所要日数の見積もりを+2日側へ改訂  →
```

一項ずつ訊かれ、各項は一文字打つたびに検査される。

- `D`（期日）に「来週」は書けない。相対表現は判定が返る日時を指していない
- `p`（確率）に「たぶん」は書けない。幅は語ではなく数値で寄せる
- `J`（判定者）に「自分の感覚」は書けない。読む手順を書き切れば、自分でも通る
- `R`（処置）に「気をつける」は書けない。書き換える対象と方向を指す

**P4（比較型）と P5（不発型）は最も安い。** 閾値の議論が要らず、`J` の裁量が入りにくい。不慣れなうちは、この二型だけで運用してよい。
