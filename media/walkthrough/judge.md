# 週一で判定する

期日が来た行には CodeLens に `○ 当たり` `× 外れ` `－ 判定不能` が並ぶ。押せば末尾の `→` が置換される。

```
[2026-08-04] P1 p=0.60 D=2026-08-11 S=PR#412 … R=…  ×
```

- 判定は記号一つ。**理由は書かない。** 外れた理由の説明、更新、後悔、いずれも要求されない
- `－`（判定不能）は「射程を書き損ねた」の実測値。恥ではなく計器の読みである
- エクスプローラの「kongyo 判定待ち」ビューにも期日到来が並び、その場で判定できる

判定済みの記号をさらに書き換えることも許されるが、`判定書換` として台帳に一行残る。破ったことは罰しない。破った回数を数えるだけである。
