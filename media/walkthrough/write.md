# 直接書く

`.kongyo` ファイル、または Markdown 中の ```` ```kongyo ```` フェンスの中で、`P1` と打って補完を受ける。七項の骨格が入る。

```
P1 p=0.35 D=2026-09-30 S=PR#412 O=mergedフラグ C=true J=GitHub API R=外れたら、見積もりを+2日側へ改訂
```

- 欠けている項は行末に `⟨欠落 D・R⟩` と出る
- 却下は打鍵のたびに波線で出る。禁止語彙には打ち消し線が引かれる
- ホバーすると「当たる世界」と「外れる世界」の一文が読める。外れる世界を書けない行は、C3（反証形）を通っていない

却下が消えたら、CodeLens の「確定して台帳へ」を押す（`Ctrl+Alt+Enter`）。確定すると `[YYYY-MM-DD]` の刻印と `→` が付き、**保存した時点で封になる**。以後、その行の本文は書き換えられない。
